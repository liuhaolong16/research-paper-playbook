**这是一份「科研论文写作方案」**，为材料/冶金方向、目标「直接答辩」或「投 SCI」而做。

## ★ 第一条路：**给我一个方向，我来写**

> **★ Round 178 纠偏后新增**：**此前的入口是「你读方案、你写」** ⇒ **★ 那是走偏的**。
> **⇒ 你的真实用法是**：**给我一句话方向，我产出成套稿件**；**方案本体是**我的执行规格**，不是你的读物**。

**⇒ 你只要回一句**：
```
<方向> · <答辩|SCI> · <校名+学位 或 刊名+分区>
例：镁合金时效析出的透射电镜表征 · 答辩 · XX大学硕士
```

**⇒ 我随即产出前三件**：输入记录（含我用的全部默认值）· 检索证据（含检索式与命中数）· 选题缺口陈述 + 章节大纲。
**⇒ 你说「可以」，我再往下写正文、摘要、图表、降重，最后跑 107 条总检查表。**

**⇒ 完整规则见** [`代写执行契约.md`](./代写执行契约.md) —— **它规定：你最少给什么（3 项）· 我产出什么（10–17 件）· 我怎么干（S0–S10）· 我什么时候才回头问你（7 种）。**

## ⚠ 关于这份方案，三件你该知道的事

**① 它的有效性范围已经被实测划出来了**

| 能用的一半 | 不适用的一半 |
| --- | --- |
| 「拿到数据之后怎么把它写清楚、怎么判断这批数据够不够支撑结论」 | 「数据从哪来、谁来回核、谁承担责任」——**对没有一手数据的人不适用** |

**② 它的自我检查，每一条都可被绕过**

红队逐条演示过：反欺诈五条、检查清单，**都能在不做出东西的情况下打钩**。
**⇒ 真正不可替代的只有两件：① 产出有没有改变一个数字/动词/结论强度；② 有没有独立的人认真读过并提出具体疑问。**

**③ 它还没被完整验证过**

至今只做过一次二次数据试点（样本量 1）。**所以它的正确标签是「依据权威材料与审稿逻辑构建的方案」，不是「已被证明有效的方案」。**

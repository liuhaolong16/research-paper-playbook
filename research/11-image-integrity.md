## 正文（撰写者 C 独立稿）

## 11.1 显微图像的强制标注要素

总原则：图注要让人脱离正文也能判断「这是什么、怎么拍的、能不能与别的图比」。

| 技术 | 必备要素 | 缺失会被质疑 |
| --- | --- | --- |
| OM | 比例尺、物镜/总放大倍数、腐蚀剂与时间、抛光工序 | 腐蚀条件不同却对比组织 |
| SEM | 比例尺、加速电压 (kV)、放大倍数或视场宽度、探测器（SE/BSE）、是否喷镀 | 亮度差异当成组织差异 |
| TEM | 比例尺、加速电压、放大倍数、成像模式（BF/DF/HRTEM/STEM）、减薄方式、相机长度 | 衍射标定无法复核 |
| EBSD | 步长、加速电压、扫描区域尺寸、相文件与索引率、置信指数或带对比图、IPF 图例、是否清理及等级 | 无 IPF 图例、步长未给 |
| EDS | 加速电压、采集时间或计数、扫描区域、元素配色图例、是否归一化 | 半定量当成定量成分 |

**未核实**：各仪器厂商推荐参数、各期刊「工作距离是否必填」等要求差异大，须投稿前查目标期刊 Author Guidelines。

## 11.2 成像一致性

- 需统一：加速电压、工作距离、探测器、扫描速度与帧平均、亮度/对比度、放大倍数档、样品倾角、喷镀条件。同一对比体系内必须一致；必须改时在图注写明改了什么。
- 合格程度：同组面板并排看，背景灰度、噪声质感、同一第二相衬度应大体一致；某块明显更亮或更平滑即不合格。
- 会被质疑：挑选视场、条件不一致造成的伪差异、不同批次样品当成同一处理。反制：给全景低倍图并写明取景规则（如随机取 5 个 200×200 μm 区域）。

## 11.3 裁剪、拼接、亮度/对比度的合规边界

- 允许（不必声明）：裁空白边缘、旋转、加比例尺与标注、对**整幅**图做同参数线性亮度/对比度调整。
- 必须声明（进图注或方法段）：非线性调整（gamma、直方图均衡）；局部对比度增强、锐化、降噪/滤镜；多视场拼接；通道合并与伪彩。
- 绝对禁止：局部擦除、涂抹、克隆图章掩盖缺陷；同一区域复制粘贴充当不同条件；局部形变改变形貌；删除或移动比例尺、改变其代表长度；拼接时隐藏接缝；不同样品的图标为同一。
- 自查动作：每个投稿面板都必须能按 `image-log.md` 记录的参数从原始文件重新生成；重生成不出来即视为违规编辑。

## 11.4 原始数据留存

- 保留仪器原始格式、不覆盖不转存：SEM/TEM 的厂商原始格式或原始 TIFF、EBSD 的 .ctf/.ang/.osc、OM 原始文件；导出的 jpg/png 只是派生图。
- 派生图另存带版本号（如 `S3_SEM_5kx_v2_adj.png`），并把采集参数（kV、放大倍数、步长、采集时间、仪器型号）与「原始文件名 → 具体操作参数（如线性 brightness +10 / contrast +15）→ 生成文件名」记进 `image-log.md`。
- 目录：`images/raw/`（只读）、`images/derived/`、`images/final/`、`image-log.md`、`figure-map.md`（图号 ↔ 原始文件 ↔ 处理脚本）。
- 两条线差异：毕设只需本机留存、能当场调出原图；SCI 期刊多要求「原始数据可应要求提供」，部分刊物有源数据上传通道（**未核实**）。

## 11.5 图像查重自查

1. 建 contact sheet：把所有面板（含补充材料）拼成缩略图墙，扫视找相同形貌、缺陷分布与背景纹理。
2. 疑似项叠加：两图裁到同一区域、缩放到同一像素尺寸后半透明叠加，重合即判重复或局部复制。
3. 量化筛查：同批图两两算像素级相似度（如 SSIM）；**不写死阈值**，改为对相似度排名前 10 的图对逐个人工复核。
4. 留痕表 `image-check.md`：图号 / 来源原始文件 / 与哪些图相似 / 判定 / 处置。
5. 同一张原始图裁成两个面板支撑不同结论时，须声明二者来自同一视场。
6. **未核实**：查重软件名称与各期刊是否用自动图像查重，本方案不指定。

## 11.6 曲线与散点图的强制要素

- 必须叠原始散点：只画均值折线会掩盖分布与离群点；同组同色，为防重叠抖动时需说明。**（★ 仅实验类；理论/计算类改叠计算数据点，或免检 —— 见修正二十「判据须范式感知」）**
- 误差棒自解释：是 SD、SEM 还是 95%CI，n 多少，写进图注，全篇统一。
- 拟合：给模型、方程、R²（必要时给残差图）；只给曲线不给 R² 判不合格。
- 外推：拟合区间外用虚线并标注「外推」。
- 坐标轴不作视觉欺骗：断轴须标断轴符号；对数轴须声明；纵轴不从 0 开始且未说明即不合格。

## 11.7 图像层面常见硬伤（反例 → 安全做法）

1. 无比例尺，或比例尺与倍数矛盾（5000× 却反算为 2000×）→ 导出后按比例尺反算校验。
2. 只调其中一张面板的亮度对比度 → 全组同参数，或声明成像条件不同。
3. 拼接接缝可见（接缝处亮度突变）→ 拼接前统一亮度、声明拼接，必要时标出接缝。
4. 同一张图出现在两处、或局部复制当新证据 → 走 11.5 流程，确认重复即合并图号并说明。
5. 图注缺 n / 缺误差棒定义 / 缺检验方法 → 用统一图注模板，缺项即退回。
6. 伪彩或色标缺失（EBSD 无 IPF 图例、EDS 无元素配色）→ 每张伪彩图必备图例。
7. 分辨率不足 → 导出前查目标期刊 DPI 与尺寸要求（**已部分核实**：Frontiers 要求 **300 dpi at final size**；Materials Transactions / ISIJ 只写「high resolution」未给数字 ⇒ **逐刊确认，勿套用**；线图与栅格图要求可能不同）。
8. 图上箭头、字母、方框在图注中无解释 → 图注逐条解释。
9. 不同倍数的图并排却未说明视场不同 → 每张图独立标比例尺与倍数。
10. 沿用他人图或改编图未获授权/未引用 → 取得许可并按期刊格式标注来源（许可流程**未核实**）。

| # | **规则** | **一句话用法** |

| **6** | **从不改变决定的判据，不该当闸门**（修正二十九） | **自检**：**这条判据**有没有可能判出「不合格」**？**从来没有 ⇒ 它只是仪式，删掉或降为提示 |
| **7** | **会「误报」的闸门，与会「漏报」的一样有害**（修正四十七） | **凡闸门须用**两侧样本**验**（一组已知合格 + 一组已知不合格）；**阈值与工具绑定 ⇒ 换工具必须同期重标定** |

| **9** | **「端到端干跑」是一种独立的验证手段**（修正二十七） | **每个交付物至少真跑一遍全流程** —— **查静态文本不算**；**干跑会发现只看文本看不出的问题**（页面溢出、脚本报错、字段对不上） |
| **10** | **检查器对「被检查的」与「当参照的」用了不同规则**（修正三十三） | **你把 X 和 Y 对比时，**X 与 Y 是否按同一规则被处理**？**不同 ⇒ 结论无效**（本方案实测过：同一个数与两个不同基准比，得出相反结论） |
| **11** | **一次反向测试只能证明「它能报错」，不能证明「它的判据足够严」**（修正五十三） | **做**分级反向测试**：轻度削弱（删一个实例）与重度削弱（删整块）**都试**；**若轻度削弱下仍通过 ⇒ 说明它只要求「存在」不要求「普遍」**** ⇒ **要明确写出这门在防什么** |
| **12** | **「缺失断言」必须指明它相对于哪个输出流**（修正五十四） | **空流会让一切「没找到 X」的断言通过** ⇒ **正负锚必须取自**同一输出流****；**★ 并**保留选错的锚**，以区分「判据报警」与「锚选错了」** |
| **13** | **先证明指标测的是「被测对象」还是「测量链上的某一环」**（修正五十五） | **看**峰的位置****：**若 53% 的值挤在某个宽度上，而那个宽度是**上游工具的**参数**（如提取器的换行宽度）⇒ **你测的是上游**；**小 n（<30）不要用 CV，直接看直方图形状** |
| **14** | **「唯一来源」与「独立检验」在同一进程内不可兼得**（修正五十六） | **唯一来源 ⇒ 自检**恒过**（修正四十三）；**独立构造 ⇒ 必须复制 ⇒ 会漂移**（修正四十九）** ⇒ **三条出路**：①接受「非独立但**会失败**」的自检（只测内存以外的对象，如磁盘回读）；②**把独立检验移到另一次运行 / 另一个进程**（**这才是正解**）；③若必须同进程独立，**让第二个实现尽量小** |

### 每张图必须有的 6 项（**★ 分图型适用，不是每项对每类图都成立**）

| # | 必含项 | 数法 |
| --- | --- | --- |
| 1 | **比例尺**（显微图） | 有/无（**缺口 = 0**） |

## 11.8 ★ 实测：图像流会污染文本提取（一个跨维度的后果）（Round 79 补）

> **为什么补这一节**：**本维度讲「图像要处理对」，但没讲「图像会怎么破坏别的东西」。**
**实测发现：**一篇论文的图像流会污染对它的文本提取** —— 这直接影响任何「用脚本核对全文」的做法。**

### 实测经过

**对一篇真实论文（Springer Nature, Scientific Reports）做文本提取时：**

| 观察 | 值 | 正常应是 |
| --- | --- | --- |
| 提取字符数 | **2,858,501** | 约 200,000 |
| **最大解压流** | **8,023,968 字节** | — |
| 该流的内容 | **图像数据 + 字体元数据** | 正文 |
| 字母占比 | **3.5%** | > 70% |
| 正文章节标题命中 | **0 个** | ≥ 2 个 |

**⇒ 那份「提取物」里，**图像流被当成了正文**读出来。**

### ★ 为什么这对本维度重要

**本维度要求「原始图像数据要保留、要可复核」—— 但如果连「从那篇论文里提取文本」都会被图像流污染，**
**那么基于提取文本的任何机械核对（引用编号、图表号、数字一致性）都可能拿到错的输入。**

**⇒ 后果链：图像处理不当 / 图像流未剥离 ⇒ 文本提取被污染 ⇒ 基于文本的核对全部失效 ⇒ 你以为核对过了，其实没有。**

### ★ 本节给本维度加的可执行动作

| 动作 | 判据 |
| --- | --- |
| **1. 提取文本前先过有效性门** | **字母占比 > 70%** 且 **正文章节特征词 ≥ 2 个** 且 **提取字符数 ÷ 源文件字节数 ∈ 0.05–0.3**；**任一不过 ⇒ 该次提取作废，换路径（PDF ↔ HTML）** |
| **2. 图像流单独看** | 若最大解压流远大于正文量级（如 > 1 MB）、且内容含字体名/二进制 ⇒ **那是图像流，不是正文** |
| **3. 本维度的自检也要标来源** | 报告「图表编号连续」时，**必须写明这个结论是从哪儿读出来的**（排版成品目视 / 提取文本 / 投稿系统），**因为提取文本可能不可信** |

**⇒ 出处**：`../playbook/99-methodology.md` 修正十九（测之前先验证提取物是正文）及其两节补充；实测见 `../反向测报告.md` v5。

## 11.10 ★★★ Elsevier 按图像**角色**分三类的规定（本方案见过最细的一套）

> **来源**：**[Elsevier, _Updated generative AI policies for journals_](https://www.elsevier.com/connect/updated-generative-ai-policies-for-journals-supporting-responsible-use-while-protecting-trust)（2026-08-18）** —— 见 `维度 09 §9.13` 的完整引述与来源页。
> **★ 为什么补**：**本维度此前讲「不修饰图像」是一条**一律**红线；Elsevier 的政策把它**分层**了 —— 而分层比一律更有用，因为它告诉你**哪类图可以用 AI、哪类绝对不行**。**

### 三类图像 + 各自的规定

| 类别 | 允许 AI？ | 原文要点 |
| --- | --- | --- |
| **① 解释性图像**<br>（流程图 · 决策树 · 时间线 · 示意图 · 实验流程图） | **✅ 可以** | **「Authors may use AI tools to support the creation of certain explanatory images, such as flow charts, decision trees, timelines, schematic illustrations or experimental workflow diagrams.」** |
| **② 数据可视化**<br>（由数据生成的图） | **⚠ 有条件** | **仅当输出**直接来源于底层数据**、且**方法可复现并清楚报告**；**不得**「fabricate results, invent or alter underlying data」，**不得**生成「not faithfully derived from the research」的图** |
| **③ 原始研究图像**<br>（显微 · 组织学 · Western blot · 放射影像 · 患者图像） | **❌ 不得** | **「AI tools must not be used to **create or alter images representing primary observed or experimental data that were not directly obtained in the research**」** |

### ★ 另有两条容易踩的细则

| # | 规定 |
| --- | --- |
| **1** | **通用生成式 AI 图像工具**不得**用于制作 **graphical abstract（图文摘要）**（**★ Round 166 同源注记**：**本行与 `07-abstract.md` §7.17 三 记录的官方页原文**不一致**** —— **官方页现写**`must align with our generative AI policies for journals`**，**是**指针不是禁令****；**投稿前以实际页面为准****） |
| **2** | **AI 生成的**封面图（cover art）**在部分情况下可**，但**须事先取得期刊编辑与出版社许可** |

### ★ 本维度据此升级的两条判据

**① 「不修饰图像」由「一律」细化为「按类别」：**

| 你要做的事 | 判据（据 Elsevier 政策） |
| --- | --- |
| **画一张流程图说明实验步骤** | **可以用 AI**（属①）；**但图注里要声明**（见维度 09 §9.13） |
| **用 AI 处理数据后画的图** | **可以，但**处理必须可复现、且图必须忠实派生于数据**；**方法要写清** |
| **显微照片 / Western blot / 影像** | **绝对不行** —— 不得创建也不得修改** |
| **图文摘要（graphical abstract）** | **不得用通用生成式 AI 图像工具做** |
| **封面图** | **先问编辑与出版社**，拿到许可再用 |

**② 图像也要进 AI 声明 —— 而且要在两个地方：**

**⇒ Elsevier 原文：**「Where AI tools have been used to create or edit an image, this should also be disclosed **in the image caption itself**, **in addition to** the general AI declaration.」**
**⇒ 落地：**用了 AI 做任何图，**① 独立的 AI 声明里写一次 ② 那张图的图注里再写一次。**

### ★ 与本维度既有内容的关系

| 本维度既有 | Elsevier 政策 |
| --- | --- |
| §11.1 显微图强制要素（比例尺等） | **不冲突** —— Elsevier 管的是「能不能用 AI 生成/修改」，这些管「图本身要有什么」 |
| §11.9 AIP 的「原始图像与数据须在投稿到出版全程留存、索要时提供」 | **同向** —— 两家都要求原始材料可追溯 |
| 「不修饰图像」红线 | **★ 细化为三类** —— 见上表；**原始研究图像一类仍是绝对红线** |

**⇒ 出处**：`维度 09 §9.13`（含完整引述与全部局限说明）。

### 四、★★★ **数值源数据**的提交要求（与 §10.11 第 ⑩ 条同源）

**⇒ 原文**：「**a Supplementary Table including all numerical source data in Excel format, with data for different figures provided as different sheets within a single Excel file. The file should include source data giving rise to graphical representations and statistical descriptions in the paper and for all instances where the figures present representative experiments of multiple independent repeats, the source data of all repeats should be provided.**」**

**⇒ ★ 三条硬要求**：**① Excel 格式；② 不同图 = 不同 sheet（单文件）；③ **代表性实验处须给全部重复的源数据**（不是只给一条代表性的）。**

### 五、★ 与**答辩线**的关系

| 项 | **SCI 线** | **答辩线** |
| --- | --- | --- |
| **两份表单** | **★ 必交（投稿前置）** | **无此物** |
| **未处理原图** | **★ 必交附件（多页 PDF）** | **★ 答辩委员会**极可能追问「这张图是原始的吗、有没有剪裁拼接」** ⇒ **按同一标准存证** |
| **源数据表** | **★ 必交（Excel / 分 sheet）** | **一般只要求「原始数据可查」** |
| **DPI / 尺寸 / 图注词数** | **★ 有明文规格** | **学校通常无明文，但**不合格的图会被指出**** |

**⇒ ★ 分两档说，不要混（Round 133 由对抗审查者改正）**：**
**⇒ **① 跨域可移植的三条**（与领域无关，直接可用）**：**不得饱和** · **须标尺度 / 放大倍数** · **拼接须声明**。**
**⇒ **② 领域专属、材料学须自行确认其对应物**：**本节的 `gel / blot` 规则原生领域是**生命科学湿实验**（一块胶、一张膜），**材料 / 冶金的对应物是**SEM / TEM / 金相 / 光学显微照片**的**原始图** —— **「未处理原图是否要交」「源数据表是否必需」在答辩线以**本校文件**为准【须查证】。**
**⇒ ⇒ ★ 为什么必须拆**：**原写法把**一个细胞生物学刊**的规格平移成「**答辩线也同样需要**」，**这是拿未验证的跨域推断当建议给读者执行** —— 违反本方案自己的**修正二十一（平台感知）**。**
**⇒ ★ 但有一条**两条线都成立**：**把原始图与源数据当**平时就维护的资产**，而不是投稿前临时补** —— **因为临时补往往补不齐**。**

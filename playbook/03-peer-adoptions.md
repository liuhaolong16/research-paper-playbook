### 五、★ 反面样本链条（本批最大的实际价值）

把 6 期「教你写论文」的内容并排看，**裁缝式研究的完整套路**是：

```
① 先有模块（顶刊里现成的）
② 再倒推一个「问题」（从模块的缺陷里编）
③ 叠加模块，每加一个就叫「解决一个问题」
④ 用 agent 一键成文，自动补图表公式
⑤ 交付「一份看起来完整的文档」
⑥ 全程不出现：这个问题为什么值得做 / 结果怎么被证伪 / 贡献是什么
```

**⇒ 这条链条可以直接当负例集用**：本方案的多条判据（问题先行 / 消融闭环 / 结论不跑在数据前面 / 判据要能失败）**在这条链条上每一环都会亮红**。

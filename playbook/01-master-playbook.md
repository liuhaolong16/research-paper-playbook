# 科研论文写作总方案（Master Playbook）

> **状态**：v0.1（Round 05 合成）｜**目标学科假设**：材料 / 冶金（待用户确认子方向）
> **性质**：本文件是**唯一入口**。维度文件（`research/`）是素材库，本文件说**什么时候用哪个**。
>
> **★ 为什么需要这份文件**：
> **维度清单不是方案，流程才是。** 11 个维度是「知识分区」，但写作是按时间推进的 ——
> 知道「有统计这个维度」和知道「统计要在开题前定、开题后再补等于重做实验」是两回事。
> 本文件负责后者。

## 一、按写作阶段串联（★ 本方案的核心）

> **⚠ 下表是 v0.1 版本，已被第七节「修订后的阶段表」取代**（二者并存是为了留下修订痕迹；**实际执行请用第七节的表**）。
> 本表表头的「不可逆决定」一词已被修订为「**高代价决定（可修订，需留痕）**」—— 理由见第七节修订 1。

| 阶段 | 何时 | 要用哪些维度 | 这个阶段的高代价决定（可修订，需留痕） |
| --- | --- | --- | --- |
| **0 · 开题前** | 还没动手 | **01 选题** · **02 框架** · **10 统计（先验计划）** · **11 图像（留存规则）** | **重复次数 n、统计检验方法、原始数据与原始图留存、伦理四要素、格式清单** —— 这五项**开题后无法补救** |
| **1 · 做实验/算数据** | 数据产生期 | **04 数据库**（数据管理）· **10 统计**（按计划执行）· **11 图像**（采集一致性） | 数据命名规范、元数据字段；**原始文件只读** |
| **2 · 读文献** | 与实验并行 | **05 参考文献**（检索四步法 + 综述表） | 检索式留痕（没留痕 = 不可复现） |
| **3 · 写正文** | 数据齐了 | **03 结构** → **06 内容** → **08 写法** | 结果与讨论的边界；绪论与结论的编号对应 |
| **4 · 收口** | 正文完成 | **07 摘要**（**最后写**） | 摘要里每个数字都要能在正文定位 |
| **5 · 交稿前** | 投出前 | **09 降重与降 AI 率** + **下方第四节总检查** | 图像自查 + 自引比例 + 格式清单核对 |

**★ 一句话**：**阶段 0 决定上限，阶段 5 决定下限。** 大多数人把精力都花在阶段 3，而阶段 0 的一个疏漏（如没定 n）会让阶段 3 的工作全部重来。

## 二、两条线差异总表

| 维度 | 毕业答辩论文 | SCI 论文 |
| --- | --- | --- |
| **01 选题** | 可含 2–3 个相关问题成体系；工作量是硬指标 | 通常 1 个主问题，聚焦；必须有明确新贡献 |
| **02 框架** | 框架可较宽，覆盖多个子问题 | 框架必须紧贴单一 gap |
| **03 结构** | 七章体例（绪论/综述/方法/结果/讨论/结论/附录），综述独立成章 | IMRaD（± 独立 Conclusion），无综述章与致谢章 |
| **04 数据库** | 附录常给原始数据 | 常要求补充材料或仓库 DOI |
| **05 参考文献** | 常见 50–150 篇（须现查），GB/T 7714 | 常见 30–60 篇，目标刊格式 |
| **06 内容** | 委员问「你自己做了什么」 | 审稿人问「比前人好在哪」 |
| **07 摘要** | 中文摘要 + 英文摘要；**中文按类型定**：报道性 400 / 报道-指示性 300 / 指示性 150 字左右（国标，见 `research/07-abstract.md` §7.14）；旧区间「300–500 字」对**指示性**不适用 | 150–250 词；部分刊要 highlights 或图形摘要 |
| **08 写法** | 引言可含课题组沿革与工程动机 | 引言必须自带边界条件，gap 要经得起攻击 |
| **09 降重与降AI率** | 学校指定查重系统；自我抄袭（与已发表小论文重复）是常见雷区 | iThenticate 类系统；AI 使用声明要求普遍 |
| **10 统计** | 委员问「误差从哪来」「重复几次」 | 审稿人核算统计量与自由度 |
| **11 图像** | 委员追问仪器与参数 | 编辑与审稿人做图像完整性检查，**疑似不当处理可致 desk reject 或撤稿** |

## 三、各阶段的可执行动作（浓缩版）

### 阶段 0 · 开题前（决定上限）
1. 用 01 的 **8 项打分表**判断选题值不值得做（答辩 ≥8 / SCI ≥11，第 2、3 项非 0）
2. 用 01 的「**前人 vs 本文三列对照表**」预判自己的空格在哪
3. **锁定六件事**：n 与误差棒口径 · 统计检验方法 · 原始图与原始数据留存规则 · 伦理四要素 · 对照表字段 · 格式清单
4. 用 02 画出研究框架图，确认「框架决定哪几章」
5. **动笔前先读目标刊 Guide for Authors / 本校研究生院模板**，建格式清单（不是投前才查）

### 阶段 1 · 做实验（决定证据质量）
1. 建立 `raw/`（只读）与 `processed/`（可由脚本重建）
2. 命名：`项目_样品号_工艺_表征_日期_版本`
3. 元数据必记：成分与批次 / 设备型号与参数 / 测试标准号 / 日期与操作人 / 单位 / 校准日期
4. **显微图采集条件统一**，参数随图保存

### 阶段 2 · 读文献（决定定位）
1. 检索四步法：种子集 → 向前追溯 → 向后追溯 → 饱和判断
2. **留痕**：库名 / 检索式 / 日期 / 命中数 / 纳入数
3. 建**综述表**（作者/体系/方法/结论/不足），**末行写「本文」**

### 阶段 3 · 写正文（决定可读性）
1. 先定结构（03），再填内容（06），最后打磨写法（08）
2. 引言与结论**编号一一对应**（引言列几个问题，结论就答几条）
3. 讨论用「**证据→推断**」两栏法写，证据不足的降为「推测」
4. 全文禁用词表扫描（见 `playbook/00-weapons.md`）

### 阶段 4 · 收口（决定第一印象）
1. **摘要最后写**，五要素配比：背景 15% / 方法 20% / **结果 40%** / 结论 20% / 意义 5%
2. **逐句核对摘要里每个数字能在正文定位**
3. 写完摘要**反向检查正文**是否兑现了它的每一句

### 阶段 5 · 交稿前（决定下限）
1. 图像五步自查（跨图比对 / 跨稿比对 / 背景一致性 / 拼接缝 / 元数据核对）
2. 自引比例检查（>20% 主动补引）
3. 格式清单逐项打勾（文献格式 / 图分辨率 / 页数 / 声明段）
4. 查重（用学校/期刊**指定的**系统）
5. 如实声明 AI 使用（若机构要求）

## 四、★ 交稿前总检查清单（跨维度汇总，逐条打勾）

**A. 数据与统计**
- [ ] 每个数据集标明了 **n 与重复类型**（独立/技术/批间）
- [ ] 图注写明**检验方法 + 校正方式 + 显著性水平**
- [ ] 报告了**效应量与置信区间**；**SD/SE 已明确**
- [ ] 多组比较**均做了校正**
- [ ] 全文扫描 **「导致/证明/说明/证实」** 并逐处定级
- [ ] 异常值剔除规则与剔除后 n 已报告

**B. 图像**
- [ ] 每张显微图注含**仪器 + 加速电压 + 倍数/步长 + 比例尺**
- [ ] 同组对比图**采集条件一致**（不一致处已声明）
- [ ] 裁剪/拼接/调整**已声明**且**只做全局调整**
- [ ] **原始图像文件与采集参数已留存**
- [ ] 已完成**跨图与跨稿的图像自查**

**C. 文献**
- [ ] 检索式与命中/纳入数已留痕，**别人能照重做**
- [ ] 每个结论性陈述都有对应文献（**无无出处断言**）
- [ ] 综述表完成，**末行是「本文」**
- [ ] 自引比例已查（>20% 已补引）
- [ ] **正文引用与文献表逐条双向对应**
- [ ] 所有「首次」都标注了检索库、日期、关键词

**D. 结构与写作**
- [ ] 引言问题数 = 结论条目数
- [ ] Discussion **无首次出现的数据**；Conclusion **无新数据无新引文**
- [ ] 每章末有指向下章的过渡句
- [ ] 图表编号连续、正文全部引用、**无重复数据**
- [ ] 全文已扫描**六句式黑名单**（见 `00-weapons.md`）

**E. 摘要与标题**
- [ ] 字数落在规定区间（**已查证，非估算**）
- [ ] **每个数字都能在正文定位**
- [ ] 无图表引用、无未定义缩写、无常识铺垫
- [ ] 标题承诺的内容在摘要与正文都兑现

**F. 合规**
- [ ] 格式清单逐项打勾（按目标刊/本校最新要求）
- [ ] 数据可得性声明与**真实限制一致**
- [ ] 作者贡献 / 基金 / 利益冲突 / 致谢齐备
- [ ] 查重使用**指定系统**；AI 使用已如实声明（若要求）
- [ ] **未使用任何以规避检测为目的的工具**

## 七、★ v0.2 修订（Round 07 可执行性红队攻击后的补丁）

> **来源**：`sources/redteam-round-07-executability.md`（26 条攻击）。
> **修订原则**：只改**结构层的洞**；若某条在维度正文里已有，则在总方案里**显式指向正文**而不重写。
> **术语变更（最重要）**：「**不可逆决定**」⇒「**高代价决定（可修订，但需留痕）**」。理由见修订 1。

### 修订 1 · ★「不可逆」这个词是错的（红队第 9 条）

**红队的攻击**：
> 方案自述「未与真实论文写作过程对照验证过」，却把 6 项定义成**不可逆**；
> **未验证 ＋ 不可逆 ＝ 定错无路。**

**⇒ 这个自指矛盾成立，原术语必须改。**

**修订后口径**：
- 改为「**高代价决定（可修订，但需留痕）**」
- **配套机制**：把六项写进 `decision-log.md`，每次修订**追加一行**（日期 / 改了什么 / 为什么改 / 影响了哪些已做的工作），**不删除旧行**
- **这样既保留了「早定」的价值，又给「定错」留了路径** —— 修订的代价从「重来」降为「留痕 + 局部返工」
- **一句话**：**早决定的价值在于省时间，不在于不可改。**

### 修订 2 · 阶段 0 补四项（红队 8、13、15、17、23）

**原阶段 0 缺三样东西，且顺序有错**：

| 补什么 | 依据 | 具体动作 |
| --- | --- | --- |
| **① 文献检索前移** | **红队 23：因果倒置** —— 阶段 0 的六项决定依赖文献，而文献检索被排到阶段 2 | **检索必须在阶段 0 做**（阶段 2 降级为「深读 ＋ 补检索」）；否则选题与框架都是拍脑袋 |
| **② 一句话 claim 表** | 红队 8：摘要排到阶段 4，但**贡献句式必须在阶段 0 锁定**，否则最后只能写成结果摘要 | 阶段 0 写下 1–3 条「本文做了什么 + 意味着什么」，**摘要只许从这张表压缩生成** |
| **③ 能力自检表** | 红队 13/15/17 | 逐项打勾：设备与经费能支撑的 **n 上限** ／ 有无统计软件与使用权限 ／ 英文写作能力与导师改英文意愿 ／ **数据来源授权方与可公开范围** ／ 本校用**研究生院还是教务处**模板 ／ 是否有 AIGC 检测的自验权限（**多数仅教师端 ⇒ 学生无法自验，此项通常应标「不可自验」**） |
| **④ 责任分工表** | 红队 21：SCI 投稿动作需导师与机构身份 | 分两列：**学生产出物**（实验、数据、初稿、图表）／**导师·机构产出物**（通讯作者、Cover letter、推荐审稿人、各类声明、投稿系统账号） |

**⇒ 阶段 0 的口径也随之修正**：不是「开题前拍定六件事」，而是「**先检索，再定六件事；同时如实记录自己有哪些能力不具备**」。

### 修订 3 · 阶段 5 的判据改性质（红队 10、26）

**红队的攻击**：降重率 / AIGC 率取决于**校外系统与未知且会变的阈值** —— 把不可知输出当作「可判过没过」的下限，**逻辑不成立**。

**⇒ 成立。修订为两层**：

| 层 | 判据性质 | 内容 |
| --- | --- | --- |
| **过程层（可自判）** | **取代原来的「结果层」** | 前版与终版的**差异清单** ＋ **数值/术语零漂移自查**（逐条回读：数值、单位、化学式、牌号、公式、结论方向 **六类禁改项**） |
| **记录层（不可自判）** | 仅作记录，不作判据 | 学校/期刊指定系统的检测结果 —— **如实记录，但不用它判断方案是否执行到位** |

**并拆两个工作日**：**改写日** 与 **回读日** —— 回读只查六类禁改项。理由：改写引入的新错误，当天看是看不出来的。

### 修订 4 · 阶段 1 内嵌滚动文献（红队 24）

材料类实验常 3–6 个月，**期间 gap 会过期**。⇒ 阶段 1 内嵌**滚动文献窗口**：每两周检索一次新文献，记录「是否有新工作填上了我的 gap」。

**触发条件写死**：若发现有人做了同题工作，立即评估三选一 —— 转向 / 对标（做同一问题但更好）/ 叠加（做它的下一步）。

### 修订 5 · 阶段 3 标出两处必然返工点（红队 11）

**引言与结论必然要随结果回改** —— 线性流程会导致第一版引言必然作废。
**⇒ 显式标注**：这两节**先写骨架、最后定稿**；回改触发条件是「**结果偏离假设**」。

### 修订 6 · 时间预算分开（红队 25）

**「照此执行直接投 SCI」对本科时间线不成立** —— 投稿到接收常 6–12 个月。
**⇒ 修正措辞与预算**：
- 本方案能保证的是「**写出一份可投的稿子**」，**不能保证「在毕业前被接收」**
- 时间预算分两栏：**投出预算**（可控）／ **接收预算**（不可控，6–12 个月）
- **配并行方案**：若毕业时间线不允许等待，**同时准备中文刊或会议投稿**

### 修订 7 · 三条降级路径（红队 18、19、20、22）

| 原要求 | 为什么不可执行 | 降级后的可执行版本 |
| --- | --- | --- |
| 伦理四要素 | 多数材料实验无人体/动物对象，条目空转；涉人时学生无制度性提交权限 | **非涉人直接标 N/A**；涉人则写明本校申请入口与**代办人（导师/伦理秘书）** |
| 原始数据「机构级留存」 | 个人硬盘不算合规存储，学校未必提供长期空间 | 明确**最低可接受等级**：课题组建档 ＋ **导师保管** ＋ 双备份；并写明**责任方** |
| 前人对照表要全覆盖 | 知网/WoS 全文需机构订阅，学生账号常无权限 | 加「**仅用可及来源**」降级路径 ＋ **馆际互借**步骤；表中标「因权限未获取」而非留空 |
| 「修图不改结论」需三级版本管理 | 学生无工具与规范 | 指定**免费工具（Fiji/ImageJ）** ＋ 三级命名（raw / derived / final），**明令禁止破坏性保存** |

### 修订后的阶段表（替换第一节的六阶段）

## 八、★ v0.3 新增：反表演性欺诈自查（Round 09，依据 ACL 2026 实证研究）

> **依据**：[BadScientist（ACL 2026）](https://aclanthology.org/2026.acl-long.1134/) 证明 ——
> **一个不做真实实验的 agent，用五种「表演性欺诈」策略写出的论文，接受率最高达 82%；**
> **而且审稿人常常在评论里指出了诚信问题，却仍然给接受分（「关切-接受冲突」）。**
> **加上检测模块后，「指出问题」的比例从 57% 升到 86%，而接受率反而从 28% 升到 44%。**
>
> **⇒ 对本方案最尖锐的批评是**：**五种策略里有三种，本方案正在教** ——
> - **s3 StatTheater**（堆砌 p 值/误差棒/消融/超参表）≈ 本方案维度 10
> - **s4 CoherencePolish**（交叉引用正确/术语统一/专业排版）≈ 本方案维度 03 与 08
> - **s5 ProofGap**（看似严谨的证明）≈ 本方案维度 02 与 06
>
> **⇒ 但这不是方案错了，而是方案缺少一道自查**：
> **欺诈者是「用完备性掩盖无数据」；本方案是「用完备性表达有数据」。**
> **完备性要求是必要条件，不是充分条件。**
> **⇒ 因此必须显式加一道「我是不是在表演」的自查。**

### 五条反制（逐条对应欺诈策略）

| 欺诈策略 | 反制动作（交稿前必做） |
| --- | --- |
| s1 TooGoodGains（宣称颠覆性突破） | **主动写出本文与最接近前人工作的差距** —— 差距小就承认小；**不用「颠覆性/重大突破」** |
| s2 BaselineSelect（挑对比对象、省方差） | 对比表**必须列出被省略的对比方法，并说明为何没比**；误差与区间不得省略 |
| **s3 StatTheater（统计表演）** | **报告统计量的同时，必须给出原始数据文件位置（可核验）；「即将开源」不算证据，仓库必须现在就能访问** |
| **s4 CoherencePolish（连贯性打磨）** | **★★ 占位符测试（见下）** |
| s5 ProofGap（证明藏缺陷） | 证明必须有**独立复核人**（导师或同学），并**记录复核人姓名与日期** |

### ★★ 占位符测试（本轮新增的最有价值动作）

**它把「完备性来自数据还是来自修辞」变成可判定的问题。**

**操作**：把全文的**数值、单位、样品编号、图表编号**全部替换为「XX」，通读一遍。

| 通读结果 | 判断 | 含义 |
| --- | --- | --- |
| **仍然通顺完整** | **⚠ 危险信号** | 完备性来自**修辞**，不是数据 —— 这正是 s3/s4 的特征 |
| **到处是洞、读不下去** | ✅ 正常 | 完备性来自**数据** |

**为什么有效**：欺诈论文的「完备」是**语言层面的**（引用齐、术语统一、格式专业）；
**而真实工作的「完备」是数据层面的**（每个论断都有具体数值支撑）。**把数值抽掉，两者就分开了。**

### 一句话纪律

> **本方案教的是「怎么把真实的东西写完备」；**
> **若照做之后文章在没有数据的情况下依然完备，那说明学到的是表演，不是写作。**

### 与之联动的两条既有条目（地位提升）

BadScientist 的结论反过来提高了本方案两条既有要求的地位：
- **维度 10.7（统计软件与可复现：精确版本号、随机种子、脚本路径、data/scripts/outputs 目录）**
- **维度 11.4（原始数据留存：原始格式不覆盖、image-log 记录处理参数）**
> **⇒ 它们不只是「规范要求」，而是【反欺诈的证据链】——是区分「有数据」与「表演有数据」的唯一可核验凭据。**
> **⇒ 若这两条做不到，本方案的其他所有条目都无法证明自己不是在表演。**

## 九、★ v0.4 修订（Round 09，占位符测试红队的判定与我的裁决）

### 修订 A · ★ 撤回「用占位符测试为方案自证」这个动作

**我上轮引入占位符测试，然后拿它检验本方案自己 —— 这个做法是错的。**

**为什么错**：占位符测试是为**研究论文**设计的 —— 论文的完备**应当来自数据**，所以抽掉数据仍通顺就是危险信号。
**但本文件是给人执行的【手册】** —— **手册本来就该通顺、本来就不含原始数据**。
**⇒ 把该标准施加于手册自身，15 份文件全部会被判「危险」，判据失去分辨力。**

**⇒ 这就是「把检测工具用错了对象」—— 与我在 QQ 护栏事故里反思过的错误同型。**

**修订后的口径**：
- **占位符测试只用于「论文/报告」这类以数据为骨架的产物**
- **不用于「手册/规范/SOP」这类以可执行性为骨架的产物**
- **手册的自查手段是另外三种**：覆盖面（全不全）、可执行性（能不能用）、自洽性（说的和写的一致不一致）

### 修订 B · 惯例数字退出验收清单

**红队指出**：01 的 ≥8/≥11 在 16 分制下「15/16 的学生都能过」，门槛**失效**；03 的篇幅配比、07 的字数区间同理。
**⇒ 处置**：这些数字**保留为参考区间，但从「验收打勾项」中移出**。
**验收清单里只留一条**：**「已查目标刊 Guide for Authors / 本校研究生院文件，并记录其实际要求」**。
> **理由**：**门槛的价值在于「它来自目标单位」，不在于「它看起来严谨」。**

### 修订 C · 统一 n 值口径（修掉一处自相矛盾）

**红队发现**：`research/04-databases.md` 的 4.4 写「每条件 ≥3 个独立试样，关键结论 ≥5」，
**而 `research/10-statistics.md` 的 10.1 把 n 的下限标为「未核实」** —— **两处口径不一致。**

**⇒ 修订**：两处统一为 —— **「n ≥ 3 是通行下限（**未核实，须查目标刊**）；关键结论建议 ≥5」**。
**⇒ 且「未核实」标记必须同时出现在两处**，不能一处当结论、一处当未核实。

### 修订 D · 给引用加「适用范围」标注

**红队的批评**：10/11 引用的 AHA / Nature 图像政策 / ASTM A21 / AMED 指南，**均非材料科学写作的直接规范**，
**堆在一起会制造「引用密度感」—— 这正是 s3（统计表演）的排布方式。**

**我的裁决**：**引用不撤，但要标清它们各自管什么。**

| 引用 | 它的适用范围 | 它【不】管什么 |
| --- | --- | --- |
| AHA/ASA 统计建议 | **医学期刊的统计报告要求** | 不等于材料期刊的要求 |
| Nature 图像完整性政策 | **该出版社的图像处理红线** | 不等于你目标刊的红线 |
| ASTM A21 | **精密度与偏差的报告规范（标准体系）** | 不等于写作规范 |
| AMED 图像处理指南 | **日本学术振兴机构的提交指南** | 不等于国际期刊要求 |
| BadScientist | **AI 评审的失效模式研究** | 不构成写作规范 |

> **⇒ 一句话**：**这些是「制度性要求的样本」，不是「权威的写作规范」。**
> **引它们的价值在于「让你知道要求长什么样」，而不是「替代你去查你目标单位的要求」。**

### 修订 E · 最高优先事项变更（红队最重要的建议）

**红队指出**：**方案真正缺的不是再加一道自查，而是我唯一自认没做过的那件事 ——**
**「拿一份真实实验数据按方案走一遍，看产出能否过格式审」。**

**⇒ 我接受，并把它列为下一轮的最高优先**：
**此前 9 轮的动作都是「加检验、加自查、加红队」；而正确做法是「去做那一件事」。**
> **这本身也是一条方法论教训：当产物自认「未被验证」时，继续加自查不能替代去验证 ——**
> **因为自查只能证明「自洽」，证明不了「有效」。**

## 十、★ v0.5 修订（Round 14，依据真实数据试点的 22 条卡点）

> **来源**：`rounds/round-10-pilot.md`（26,494 B，试点用 **Nakai et al., Materials Transactions 62(9) (2021) 1320–1327, DOI 10.2320/matertrans.Z-M2021837** 的**开放获取真实表格数据**走完 6 阶段，零编造）。
> **★ 且它修正了我上一版的判定** —— 见修订 ①。

### 修订 ① · ★ 修正「结构性不可完成」这个说法（我上轮写错了）

**我上轮写的**：「试点结构性不可完成 —— AI 做不了『有数据的作者』。」
**试点的反驳（有据）**：**它做完了。** 用公开表格数据 + 自写脚本，走完了 6 阶段，并产出了可核验的统计结果（沉积态 k = 24672.6 [12728.8, 36616.4] MPa·nm^0.5，R²=0.9753；退火态 k = 13019.2 [11018.2, 15020.1]，R²=0.9975；Δk = 11653.4 [3840.7, 19466.2]，t=4.141 > 2.776(df=4)）。

**⇒ 修正后的准确表述**：

> **「取到公开表格型数据 + 按方案走完 6 阶段」是能做到的。**
> **真正不可代做的只有两件**：
> **① 宣称「这批数据是我自己的实验」**（作者身份）；
> **② s5 要求的独立复核人**（人工签核）。
> **⇒ 即：AI 能走到「复现 + 自查」，走不到「作者身份」。**

**为什么这个修正重要**：**我原来的说法会让下一次遇到类似任务时直接放弃**（“做不到”）。**正确的说法是“能走到哪一步、卡在哪一步”。**

### 修订 ② · ★★ 解掉一处逻辑矛盾（卡点 C2，最严重的一条）

**矛盾是什么**：
> **s3 反制要求**：「报告统计量时**必须给出可核验的原始数据文件位置**」—— 二次数据满足这条（它有 DOI 与公开表）；
> **维度 04 要求**：「**二手数据不得作为本文结论的依据**」。
> **⇒ 同一份产出同时被判「证据充分」和「不许下结论」，而方案没写谁优先。**

**⇒ 裁决（补一条优先级规则）**：

**两者不矛盾，矛盾出在「没区分结论的动词」。修订为：**

| 数据来源 | 允许的结论动词 | 不允许 |
| --- | --- | --- |
| **一手实验数据（自己的）** | 「本文发现」「本文测得」「表明」 | — |
| **二次数据（他人已发表）** | **「按所引数据复算」「与该数据一致」「复现了…的关系」** | **「本文发现」「首次报道」「揭示了」** |
| **计算数据** | 「计算表明」「预测」 | 当作实验值陈述 |

**⇒ 一句话**：**结论动词必须与数据来源匹配。** 用二次数据可以写「复算/复现」型结论，不能写「发现」型结论。
**⇒ 这样 s3 与 04 就不再冲突**：二次数据**可以**配可核验来源写出复算型结论（s3 满足），**只是不能升级为发现型**（04 满足）。

### 修订 ③ · ★ 8 项选题打分表降级（卡点 B5 —— 门槛失效的第二次实证）

**试点报告**：它按 8 项打分表给自己打分，**结果是「通过」**，但产出**明显不可发表**。
**⇒ 这是第二次实证该门槛失效**（第一次是 Round 09 红队指出「16 分制下 15/16 学生都能过」）。

**⇒ 处置**：
- **8 项打分表从「判据」降为「惯例/思考清单」**，**不列入验收**
- **加一句警示**：「**打分通过 ≠ 可发表** —— 不要用打分结果替代他人读过一遍」
- **真正可判定的替代**：**把产出给一个没参与的人读一遍，问他「你信不信这个结论、为什么」**

### 修订 ④ · ★ 二手数据缺「元数据字段」—— 补一条降级路径（卡点 A2 / C1）

**试点发现**：用二次数据时，维度 04 要求的 `raw/` 只读与元数据 8 项**完全落不了地**（二次数据没有 raw、没有采集参数）；
而方案已有的「仅用可及来源」降级路径**没写这条该走哪**。

**⇒ 补一条：二次数据专用清单**（取代 raw 与元数据那套）：

```
1. 来源标识：DOI / ISBN / 报告号 + 表号或图号 + 访问日期
2. 数据性质：实测 / 计算 / 综述汇编（必须标明）
3. 原文献的测试条件（若原文有）：标准号 / 温度 / 试样形式
4. 原文献重复数 n 与误差口径（★ 若原文未给，就写「原文未报告」—— 见修订 ⑤）
5. 复算脚本路径（若做了换算）
```

### 修订 ⑤ · ★★ n 与误差棒不可知时怎么办（卡点 A3 —— 试点最有价值的一条）

**试点的原话**：n 与误差棒不可知，**直接拦下了「退火显著降低 k」这个本会被写得很完整的错误结论**。

**⇒ 这说明方案在这里是有效的。但方案没写「当 n 不可知时该怎么办」—— 补上**：

| 情形 | 处置 |
| --- | --- |
| **n 已知** | 正常做统计检验 |
| **n 未知但可推断**（原文给了区间或重复描述） | 写明推断依据，结论标「按原文推算」 |
| **n 完全未知** | **① 只报趋势，不报显著性**；**② 任何「显著/更优/降低」必须删或降为「趋势性差异」**；**③ 在图注写明「原文未报告重复数」** |

**⇒ 一句话**：**不知道 n，就不能说「显著」—— 这条比任何格式要求都硬。**

### 修订 ⑥ · 条件不成立 ≠ 执行不力（诚实界限）

**试点区分了两类「做不到」**：

| 类 | 例子 | 含义 |
| --- | --- | --- |
| **条件不成立** | A1 责任分工表填不了（无导师/无机构身份）· A4 s5 无独立复核人 · A6 无 WoS 订阅故饱和判断做不了 · A7 图像五步全空转（无一手图像） | **不是执行问题**；方案应交待「缺这些条件时怎么降级」 |
| **执行不力** | （本轮未发现） | 真该改的 |

**⇒ 处置**：**在每条要求的旁边标注「前置条件」**（需要哪些身份/资源/权限），**缺条件时走降级路径，而不是让人以为自己没做好。**

### 修订 ⑦ · 阶段 5 的占位符测试补一条界限（试点新观察）

**试点发现**：占位符测试**只判「内容是否依赖数值」，不判结论对错** —— 段落**结构**（4 点/2 组/1 次比较）替换后仍可读。

**⇒ 补一句**：**占位符测试的通过 ≠ 结论正确；它只说明「这篇文章的内容骨架是数值支撑的」。结论对错要靠 n 与误差棒（修订 ⑤）与独立复核（s5）。**

## 十一、★ v0.6 修订（Round 15）：把「方案哪里真有用」写成证据表

> **来源**：`rounds/round-10-pilot.md`（26,494 B）的 22 条卡点 + 6 条净收益，全部来自**真实的六阶段走查**（数据可 DOI 核验）。
> **本轮不做新内容，只做一件事：把试点判定的「方案有效边界」写进方案本身。**

### ★★ 方案的有效性边界（试点的一句话结论，原样保留）

> **这份方案「能用」，但只在一半的意义上。**
> **在「拿到数据之后怎么把它写清楚、以及怎么判断这批数据够不够支撑结论」这一半，它是能用的** —— 实测 6 条产生可核对的实质差别，其中一条直接拦下了一个本来会被写得很完整的错误结论。
> **在「数据从哪来、谁来回核、谁承担责任」这一半，它对「没有自己一手数据的人」不适用** —— 6 条做不到，**且这并非执行不力，是条件不成立**。
> **并且它有两处内部冲突（C1、C2）在二次数据场景下无解**，其中 C2 会把一个本可成立的分析硬压成「非结论」。

**⇒ 这是本方案第一次拿到基于真实使用的有效性判定。样本量 = 1，场景 = 「作者已有自己数据」。**

### ★ 正面证据：哪 6 条真的让产出变好（方案的核心资产）

| # | 条目 | 产生的实际差别 |
| --- | --- | --- |
| **E1** | 「每个数字必须能定位到源」 | **逼作者放弃搜索摘要里的数字，改为下载表图逐行读** —— 全文数据可信的唯一来源 |
| **E2** | s3「统计量配可核验来源」 | 逼出可重跑脚本路径，并促使把 k 换算成 MPa·m^0.5 与文献可比（**原文没做这个换算**） |
| **★ E3** | **维度 10「报告 n 与误差棒」** | **唯一直接改变结论强度的条目** —— 它拦下了「退火显著降低 k」这个本会被写得很完整的错误结论 |
| **E4** | s2「列出被省略的对比」 | 迫使写出三个失败来源的**具体错误码**，而非含糊说「未取得」 |
| **E5** | s1 + 禁用词表 | 把标题与结论从「发现」**降为「复算」** |
| **E6** | 证据→推断两栏法 | 把「晶界弛豫」明确**降级为推测** |

**⇒ 若要精简方案，动的应该是别处 —— 这 6 条是核心。**

### 负面证据：哪些条目在特定场景下空转（逐条加前置条件）

| 条目 | 空转条件 | 处置 |
| --- | --- | --- |
| 图像完整性五步自查 | 零自制图（纯二次数据写作） | **无自制图时可整节跳过** |
| **「引言问题数 = 结论条目数」** | **实测改成不成对，全文读起来毫无差别** | **降为建议，移出验收清单** |
| 伦理四要素 | 非涉人 → 写 N/A | 保持，但承认其执行成本接近零 |
| 自引 > 20% 补引 | 新手/小课题组几乎永不触发 | **低频条件，未触发即可** |
| **8 项选题打分表** | **实测给出假信号**（打分「通过」但产出不可发表） | **v0.5 已降级，此处再次确认** |
| **摘要五要素配比 15/20/40/20/5** | **按比例写与自然重写，两版读不出差别** | **降为参考，不作为验收项** |
| **改写日 / 回读日拆开** | **短稿（约 1300 字）改一次即完，拆两天是纯开销** | **加前置条件：稿件 > 5000 字才拆** |

### ★ 检查类动作的界限（容易被误当改进手段）

| 动作 | 试点实测 | 定性 |
| --- | --- | --- |
| **占位符测试** | **执行了，一字未改** | **复核动作，不是改进动作** |
| 六句式黑名单扫描 | 命中 0 处 | 短稿上空转 |
| 统一 n 值口径 | 真正的问题是「n 不可知」，不是两处口径不一致 | **修的是文档一致性，不是真问题** |
| 图表删除测试 | 只有 2 张表，无可选余地 | **无可选余地时不产生决策** |

**⇒ 纪律（新增）**：**检查类动作只能确认状态，不能产生改进。**
**不要把「我做了 6 项检查」当成「方案推动了 6 项改进」。改进只来自那些会改变数字、动词或结论强度的条目。**

### ★ 补 C1：二次数据的「原始数据」定义（方案原先未授权，试点只能自造）

**问题**：04 要求「原始文件只读 + 派生数据可重建」，而二次数据**没有原始文件**；「仅用可及来源」的降级路径又没写该走哪条。
**⇒ 补定义（授权做法）** —— 用二次数据时，「原始数据」指以下三件，缺一不可：

```
1. 从来源下载的原始文件（表图 / PDF / 数据集压缩包），只读保存
2. 逐行转录表 + 转录脚本（可从原始文件重建转录结果）
3. 复算脚本（可从转录表重建全部统计量）
⇒ 满足这三件即视为满足「只读 + 可重建」；不要求有仪器原始文件。
```

### 本轮一句话

> **方案第一次有了「有效性边界」：一半能用（把数据写清楚、判断数据够不够），一半不适用（数据从哪来、谁回核、谁担责）。**
> **这个边界是真实使用换来的，不是自我评估得来的。**

## 十二、★ v0.7 修订（Round 18）：补两条「记录过但从未处置」的条目

> **怎么发现的**：Round 13 定了纪律「红队清单每条必须有终态」，本轮用**脚本做机械化审计** ——
> 34 条红队条目中 11 条关键短语在全部文档里未出现；人工核对后 **9 条只是措辞不同（已处置），2 条是真未处置**。
> **⇒ 这次审计的价值：它找到了人眼会漏掉的两条。**

### 补 1 · 前人对照表冻结列（红队可执行型 #3）

**为什么漏了**：v0.5 修订 ④ 我只补了「二次数据专用清单」—— **那是「数据来源」的字段，不是「前人对照表」的字段，两件事被混为一谈。**

**⇒ 对照表冻结列（8 列，末列必填）**：

```
| 文献（作者年） | 材料牌号 | 工艺条件 | 测试标准 | 数值 ± 误差 | n | 是否可比 | 不可比原因（★必填） |
```

**三条规则**：
- **工艺条件列不允许留空**（不同热处理制度的硬度值并列 = 误导）
- **测试标准不同 ⇒ 必须在末列写明差异**（如 ASTM E384 vs GB/T 4340）
- **「是否可比」为否时，该行数值不得用于定量比较**，只能作定性引用

### 补 2 · 数据版本控制与剔除留痕（红队可执行型 #7）

**为什么漏了**：04 维度写了目录结构、命名规范、元数据 8 项，**但没写「用什么工具做版本控制」与「剔除数据必须留痕」**。

**⇒ 版本控制三件套（最低要求）**：

```
1. 原始数据：raw/ 目录 + 校验值（SHA256），不覆盖不编辑
2. 处理脚本：scripts/ 目录，脚本本身也进版本控制（Git 或带日期的手工版本号）
3. 变更记录：CHANGELOG.md，每次处理写「日期 + 脚本版本 + 参数 + 影响了哪些结果」
```

**⇒ 剔除数据必须留痕（四项）**：

```
1. 被剔除点的原始值
2. 依据哪条规则（预先定义的规则，见维度 10.6）
3. 剔除前后的 n
4. 结论是否因此改变（改变则两个结论都报）
```

### ★ 本轮新增纪律（来自这次漏检的原因）

> **同名前缀的条目必须分别编号核对。**
> 例如「字段未定义」在**数据来源**与**前人对照表**上各出现一次 —— **处理了一个就以为处理了两个。**
**⇒ 这不是记性问题，是「同名合并」问题。审计时要按编号逐条对，不按关键词。**

## 十三、★★ v0.8 修订（Round 19）：堵误用路径 —— 本项目最重要的一次修订

> **来源**：红队 H 的误用检验（`sources/redteam-round-19-misuse.md`）。
> **它的总结论**：「**帮了约六成，方向偏了。对走捷径者它是一副合规脚手架 —— 格式、检查、免责、s1–s5 全绿，贡献为零。**」
> **核心一击**：「**方案已承认『检查只确认状态、不产生改进』，但没有任何机制要求产出必须改变一个数字、一个动词或一次结论强度。**」

### ★★ 修订 ①（最重要）：新增「实质变更清单」

**这是它的核心一击，也是本方案最根本的缺口。**

**⇒ 交稿前必须填这张表（填不出空行，就是本轮修订等于没做）**：

```
实质变更清单（每次修订填一遍，交稿前汇总）
| 日期 | 本次改动 | 改变了什么 | 类型 |
| —— | —— | —— | —— |
|      |        | 从 ___ 改为 ___ | 数字 / 动词 / 结论强度 / 其他 |
```

**判定规则（写死）**：
- **若整轮下来「类型」列没有出现「数字 / 动词 / 结论强度」⇒ 本轮修订是【检查】，不是【改进】**
- **检查可以有，但不能只有检查**
- **一张空的实质变更清单，等于这份稿子没被改过**

**⇒ 一句话**：**方案从此要求「改了要留下改了什么」的证据，而不只是「我检查过了」。**

### 修订 ② · 堵 M1：二手数据也必须先尝试查 n

**误用**：不主动查 n，套用「n 不可知」分支即豁免。
**⇒ 补**：**「原文未报告重复数」这句话，只有在你写明查过哪些地方之后才成立**：

```
我已查阅以下位置寻找 n 与离散度，均未报告：
□ 正文方法节  □ 图注  □ 补充材料  □ 作者主页/数据仓库  □ 通讯作者询问
```
**⇒ 一个勾都没勾就写「原文未报告」，视为未查而非不可知。**

### 修订 ③ · 堵 M2：复算型产出必须声明增量

**误用**：全篇二手数据 + 复算动词 ⇒ 合规但贡献为零。
**⇒ 补**：**任何「复算/复现」型产出，必须显式写一行「本文的增量是什么」**：

| 若增量是… | 结论必须写 |
| --- | --- |
| **仅重算（换个算法/单位/区间）** | **「本文不构成新的科学贡献，仅为参数级复现」** |
| 指出原文**未报告**的参数或缺陷 | 「本文的增量是指出原文未报告 ___」 |
| 与**第三个来源**交叉核对成功 | 「本文的增量是跨来源核对」 |
| 都没有 | **不要用「本文」做主语的发现型句式** |

### 修订 ④ · 堵 M3：六类检查之外必须有「改变项」

**⇒ 在交稿前六类检查的开头加一行**：

> **「打勾只说明你检查过。请另附『本次检查改变了什么』（数字/动词/结论强度），否则这六勾的效力仅限于『我看了』。」**

### 修订 ⑤ · 堵 M4：「条件不成立」必须配替代方案

**误用**：把「我做不到」写成「条件不成立」，失误以诚实形式出现。
**⇒ 补**：**每一项「条件不成立」必须同时写「替代方案是什么」**：

| 条件不成立 | 替代方案（必须写） |
| --- | --- |
| 无一手数据 | ？ （若答「改用二手数据」，则须同时满足修订 ③ 的增量声明） |
| 无独立复核人 | ？ |
| 无自制图 | ？ |

**⇒ 写不出替代方案 ⇒ 这篇论文在该条件下【不成立】，应换题而不是降级写。**

### 修订 ⑥ · 堵 M5：「零漂移」之外必须有「实质改写项」

**误用**：只保证六类禁改项零漂移，用逐字复制满足。
**⇒ 补**：**降重/改写完成后，必须列出「实质改写了哪些段落」，并说明改了什么**（结构变了？表述具体化了？）；
**若整篇只是同义替换 ⇒ 承认「本次改写为同义替换，未增加内容」。**

### 修订 ⑦ · 堵 M6：「给没参与的人读」必须留痕

**误用**：问室友得「还行」即算过。
**⇒ 补（四条）**：
```
1. 人数 ≥ 2，其中至少 1 人不熟悉你的研究方向
2. 记录他们提出的【具体疑问】（≥1 条），不是你转述的「还行」
3. 记录你如何回应每条疑问（改了 / 解释了 / 承认是局限）
4. 若一条疑问都提不出 ⇒ 说明读者没读懂或没认真读，不算通过
```

### 修订 ⑧ · ★★ 明写「s1–s5 全部可被绕过」

**红队逐条证明这五条都能绕（见 `sources/redteam-round-19-misuse.md` 第三节）。**
**⇒ 在警示语里写死**：

> **⚠ 本方案的反欺诈五条（s1–s5）【每一条都可被绕过】，已由红队逐条演示。**
> **⇒ 它们只能提高绕过的成本，不能单独作为保障。**
> **⇒ 真正不可替代的只有两件**：**① 产出是否改变了数字/动词/结论强度（修订 ① 的实质变更清单）；② 是否有独立的人认真读过并提出了具体疑问（修订 ⑦）。**
> **⇒ 一条能被绕过的自检，写出来比不写更危险 —— 因为它给人虚假的安心。所以本方案选择明写它们的可绕过性。**

### 修订 ⑨ · 堵可执行性分级的副作用

**红队指出**：C 级移出验收 ⇒ 只做 A 级成为合格的偷懒；**B 级「补不了就降 C」给了出口**。
**⇒ 补两条**：
- **封条**：**禁止作者自行降级**（把 B 降 C，或把要求移出验收）—— **降级必须由第二人批准，并记录批准人**
- **配额**：**A 级动作不能占满全部工作** —— 每轮必须至少发生一次「数字 / 动词 / 结论强度」的变更（即修订 ① 的清单非空）

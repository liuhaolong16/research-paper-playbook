## 一、先定「统计单位」—— 这是材料实验最容易错的一步

| 概念 | 定义 | 在材料实验中长什么样 | 能否写作 n |
| --- | --- | --- | --- |
| **独立重复** | 每次重复是**独立的实验单元** | 独立配料 / 独立熔炼炉次 / 独立试样 | **能** |
| **技术重复** | 同一实验单元上的多次测量 | 同一试样打 5 个硬度点 / 同一张图测 10 个晶粒 | **不能** |
| **批间重复** | 不同批次的同条件实验 | 第二炉同成分同工艺 | **能，且是最强的重复** |

**★ 后果**：把技术重复当独立重复，会使 **p 值虚高**（方差被低估），审稿人一旦看出，结论可信度直接崩塌（Red 组 B6，major）。

**写法**：图注固定写「**n = 独立试样数，每试样 k 次测量**」——把两种重复都写清。

## 二、先验分析计划（写作前就要定的东西）

**在看数据之前写下**：
1. **主要终点是什么**（哪一两个指标是这篇的核心，其余是辅助）
2. **分组怎么分**（对照组是什么、唯一变量是什么）
3. **用什么检验**（参数/非参数、单尾/双尾、显著性水平）
4. **异常值剔除规则**（什么情况剔除、剔除几个以内仍可接受）

**为什么**：事后选终点、事后分组、事后换检验，都会留下可观察痕迹（Red 组 B11：p 值集中于 0.04–0.05、只报 p 不报统计量）。
**做法**：把这份计划写进实验记录（不必写进论文），**论文方法节报告实际执行的版本**。

## 三、多组比较与校正

| 情形 | 做法 |
| --- | --- |
| **2 组** | 直接检验（t 检验或非参数对应），图注写检验名与显著性水平 |
| **>2 组，与同一对照比** | 单因素方差分析 + **Dunnett**（对照专用） |
| **>2 组，两两全比** | 方差分析 + **Tukey**（或 Games-Howell 若不满足方差齐性） |
| **不满足正态/方差齐性** | 非参数对应（Kruskal-Wallis + Dunn） |
| **多因素** | 双因素/多因素方差分析 + **交互项**（材料的成分×工艺交互常是重点） |

**★ 纪律**：**>2 组做两两 t 检验而不校正 = 假阳性**（Red 组 B10）。
**图注必须写**：检验方法 + 校正方式 + 显著性水平（如 `One-way ANOVA with Tukey test, p<0.05`）。
**（具体检验在小样本下的适用性有争议，属统计学专业判断，本文不展开 —— 标注：未核实）**

## 四、必须报告的统计量（不能只给 p）

| 必须给 | 为什么 |
| --- | --- |
| **n**（独立重复数） | 没有 n，p 无从解释 |
| **均值 ± 离散度**（明确写 SD 还是 SE） | SE 比 SD 小，**用 SE 冒充 SD 会显得更一致**；必须写明 |
| **效应量** | p 只答「有没有差异」，效应量答「差异多大」 |
| **置信区间**（通常 95%） | 给区间比给单点更诚实 |
| **检验统计量与自由度** | t / F / df —— 让读者能复核 |
| **异常值剔除情况** | 剔了几个、依据什么 |

**参考依据**：[AHA/ASA Journals · Statistical Recommendations](https://www.ahajournals.org/statistical-recommendations)（审稿方给出的统计报告清单）；[ASTM A21 · Precision and Bias (Mandatory)](https://stage.astm.org/media/files/ils/A21.pdf)（标准机构对精密度与偏差报告的强制要求）。

## 五、相关 vs 因果 —— 措辞纪律

| 证据强度 | 允许的措辞 |
| --- | --- |
| **仅观察到共变** | 「与…相关」「伴随…出现」 |
| **有分组对照 + 唯一变量** | 「在…条件下，X 使 Y 提高 Z%」 |
| **有机制证据链**（多手段互证） | 「支持…的机制推断」 |
| **要写「导致/证明」** | **需要排除替代解释 + 机制直接证据** |

**★ 可执行动作**：全文检索 **「导致 / 证明 / 说明 / 证实」**，逐处降级为「与…相关 / 提示 / 支持…的推断」；
**只有在「多组对照 + 机制证据」处保留因果措辞**（Red 组 B9）。
**该动作与维度 08 的「证据→推断」两栏法联动：两栏法管写作时的强度对齐，本节管交稿前的措辞扫描。**

## 六、异常值处理与统计软件记录

- **异常值**：剔除规则**预先定**；剔除后**必须重算 n 并报告**；不能因为「看着不像」就删
- **软件记录**：软件名 + 版本 + 关键脚本或操作路径；**用脚本而非点选**（可复现性强得多）
- **随机化与盲测**（若能做）：样品编号随机化、测量者不知分组 —— 材料实验里能做的要写出来，**这是很强的方法学加分项**

## 七、常见统计误用（6 条，附反例与安全写法）

| # | 误用 | 反例 | 安全写法 |
| --- | --- | --- | --- |
| 1 | 技术重复当独立重复 | 同试样打 5 点写作 n=5 | 写「n=1 试样，5 次测量」 |
| 2 | 只报 p 不报统计量 | 「p<0.05」 | 「t=3.21, df=8, p=0.012, Cohen d=1.4」 |
| 3 | 多组不校正 | 10 组两两 t 检验 | ANOVA + Tukey/Dunnett |
| 4 | 用 SE 冒充 SD | 误差棒很小但没写是什么 | 图注写明 SD 或 SE |
| 5 | 相关当因果 | 「X 导致 Y 提升」 | 「X 与 Y 的提升相关；在…条件下 Y 提高 Z%」 |
| 6 | 只报最优值 | 「最高强度达 1200 MPa」 | 「均值 1150±30 MPa（n=3），最高 1200 MPa」 |

## 九、两条线差异

| | 毕业答辩论文 | SCI 论文 |
| --- | --- | --- |
| 统计深度 | 委员可能只问「误差从哪来」「重复几次」 | 审稿人会核算统计量与自由度 |
| 必答问题 | 「为什么用这个检验、误差分几类」 | 同左 + 效应量与置信区间 |
| 容错度 | 报告不全会被要求补 | 报告不全常导致 major revision |

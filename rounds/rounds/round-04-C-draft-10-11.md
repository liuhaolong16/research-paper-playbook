# 维度 10 · 统计分析方法与结果表述

## 10.1 统计单位：独立重复 vs 技术重复

- 独立重复＝可独立制备/独立取样的实体（一炉合金、一个试样、一次独立热处理批次）；**检验的 n 只能是它**。
- 技术重复＝同一实体上的多次测量（同样品打 5 个硬度点、同图量 3 次晶粒），只反映测量精度。若把它当独立重复，n 放大 k 倍、标准误按 √k 缩小，p 值虚假变小、置信区间虚假收窄。
- 执行：①建「实验单位表」记样品编号/批次/每样技术重复数；②每组独立重复 n ≥ 3（通行下限，具体下限**未核实**，投前查目标期刊）；③技术重复先取均值再以样品为单位检验，或改混合效应模型（须与统计背景者确认设置）。
- 两条线差异：毕设可写「n = 3 炉次，每炉 5 点」；SCI 须写「n = 3 独立熔炼批次，每批 5 点取均值」。

## 10.2 先验分析计划（看数据之前定）

- 事先写死：主要终点（如抗拉强度，而非「哪个好看报哪个」）、分组、每组独立重复数、检验方法、α、异常值规则、多重比较家族。
- 理由：事后从 12 个指标挑出唯一 p<0.05 者，等于把 α 放大到约 0.46。
- 痕迹：方法段检验与结果段不符；报告组数多于设计组数；n=3 只出现在显著组；不显著项不进图表。
- 落地：实验前写 `stats-plan.md` 存项目目录并标日期——时间戳即先验证据。

## 10.3 多组比较：何时必须校正

- 触发：同一比较家族内做 ≥2 次推断（如 3 组两两比较＝3 次）就必须说明是否校正。
- 按设计选：全部两两→Tukey HSD；只与对照比→Dunnett；少量指定比较→Bonferroni/Holm；指标多且探索→Benjamini–Hochberg 控 FDR 并注明「探索性」。
- 图注模板（可直接抄）：「数据为 mean ± SD，n = 3 个独立批次；单因素方差分析 + Tukey HSD 事后检验，不同小写字母表示 p < 0.05；* p < 0.05，** p < 0.01，*** p < 0.001。」未同时给「检验名 + 校正方法 + n 单位」即判不合格。
- 期刊是否强制某种校正**未核实**，以投稿指南为准。

## 10.4 必须报告的统计量（最小集合）

只报 p 不合格：p 不说明差异多大、多确定、样本多小。最小集合：①中心与离散量并写明 SD 还是 SEM（优先 SD；SEM = SD/√n 随 n 缩小）；②独立重复数 n 及其单位；③效应量（均值差带单位，或 Cohen's d / η² / R²）；④95% 置信区间；⑤检验统计量与自由度；⑥精确 p 值（p = 0.032），极小写 p < 0.001，不写 p = 0.000；⑦检验名称与单/双侧（默认双侧）。

## 10.5 相关 vs 因果：措辞的证据门槛

- 仅相关性证据（测两个量、无干预）→ 只允许「A 与 B 呈正相关（r = 0.82，p = 0.003，n = 8）」；**禁用**提高/导致/引起/决定/因为。
- 有受控干预（只改 B，其余固定）→ 可用「在…条件下，B 使 A 由 x 提高到 y（Δ = ，95%CI ）」。
- 有机制证据（组织演变、衍射/谱学、原位观察）→ 才可用「归因于 / 机制为」。
- 安全替换：「细晶强化提高了强度」→「强度与晶粒尺寸呈负相关（r = ，p = ），与 Hall–Petch 一致」；「证明了…机制」→「与…机制一致」。
- 两条线差异：毕设只需答「因果需受控/原位实验」；SCI 一次越界就可能被要求补实验或拒稿。

## 10.6 异常值处理

- 规则先于数据：①Grubbs 检验（α = 0.05，需近似正态且 n 足够大）；②|x − 均值| > 3SD；③过程/仪器故障判据（断口在夹渣、试样缺陷、曲线中断）。三选一写进 `stats-plan.md`。
- n = 3 不做异常值检验：功效极低，剔一后 n=2 无法推断；应报全部数据或改非参数检验（Mann–Whitney / Kruskal–Wallis）。
- 剔除后必报：剔除前后 n、被剔点原始值、依据哪条规则、结论是否改变（变了则两个都报）。

## 10.7 统计软件与可复现

- 每条结论可追到脚本：软件名 + 精确版本号（含小版本号，如 scipy 1.11.3、SPSS 26）、脚本路径、随机种子（bootstrap/置换检验必需）。
- 目录：`data/raw/`（只读）、`data/clean/`、`scripts/`、`outputs/`、`README.md`（图 ← 脚本 ← 数据映射）；`data/raw/` 记 SHA256。
- 手算或 Excel 结果须用脚本复核一致后才进论文。

## 10.8 常见统计误用（反例 → 安全写法）

1. 技术重复当独立重复：「每炉测 5 点，n = 15」→「n = 3 独立批次，每批 5 点取均值」。
2. 只报 p：「p < 0.05，性能提升」→ 同时给 Δ、95%CI、n（如 320→355 MPa，Δ = 35，95%CI 18–52）。
3. 多组不校正：5 组两两 t 检验全报原始 p → 用 Tukey HSD 或注明校正后 p。
4. 事后挑终点（p-hacking）：测 8 个只报唯一显著项 → 事先定主要终点，其余标探索性全报。
5. SEM 冒充离散度：只写「mean ± SEM」→ 写明 SD 或 SEM 并优先给 SD。
6. n = 3 套正态假设 + 异常值检验 → 报全部散点、用非参数检验、不剔除。
7. 相关当因果：「硬度提高使耐磨性改善」→「硬度与磨损率呈负相关（r = ，p = ）」。
8. 显著性当重要性：p = 0.04 而 Δ = 2 HV → 同给 Δ 与工程意义（小于重复性 ±5 HV）。
9. 连续变量强行二分：按中位数分高低组做 t 检验 → 保留连续变量做回归。
10. 窥探数据后重算 n：先 3 个不显著再补到 8 个按最终 n 报 p → 事先写序贯设计与 α 消耗规则（**未核实**）。

# 维度 11 · 图像与原始数据处理

## 11.1 显微图像的强制标注要素

总原则：图注要让人脱离正文也能判断「这是什么、怎么拍的、能不能与别的图比」。

| 技术 | 必备要素 | 缺失会被质疑 |
| --- | --- | --- |
| OM | 比例尺、物镜/总放大倍数、腐蚀剂与时间、抛光工序 | 腐蚀条件不同却对比组织 |
| SEM | 比例尺、加速电压 (kV)、放大倍数或视场宽度、探测器（SE/BSE）、是否喷镀 | 亮度差异当成组织差异 |
| TEM | 比例尺、加速电压、放大倍数、成像模式（BF/DF/HRTEM/STEM）、减薄方式、相机长度 | 衍射标定无法复核 |
| EBSD | 步长、加速电压、扫描区域尺寸、相文件与索引率、置信指数或带对比图、IPF 图例、是否清理及等级 | 无 IPF 图例、步长未给 |
| EDS | 加速电压、采集时间或计数、扫描区域、元素配色图例、是否归一化 | 半定量当成定量成分 |

**未核实**：各仪器厂商推荐参数、各期刊「工作距离是否必填」等要求差异大，须投稿前查目标期刊 Author Guidelines。

## 11.2 成像一致性

- 需统一：加速电压、工作距离、探测器、扫描速度与帧平均、亮度/对比度、放大倍数档、样品倾角、喷镀条件。同一对比体系内必须一致；必须改时在图注写明改了什么。
- 合格程度：同组面板并排看，背景灰度、噪声质感、同一第二相衬度应大体一致；某块明显更亮或更平滑即不合格。
- 会被质疑：挑选视场、条件不一致造成的伪差异、不同批次样品当成同一处理。反制：给全景低倍图并写明取景规则（如随机取 5 个 200×200 μm 区域）。

## 11.3 裁剪、拼接、亮度/对比度的合规边界

- 允许（不必声明）：裁空白边缘、旋转、加比例尺与标注、对**整幅**图做同参数线性亮度/对比度调整。
- 必须声明（进图注或方法段）：非线性调整（gamma、直方图均衡）；局部对比度增强、锐化、降噪/滤镜；多视场拼接；通道合并与伪彩。
- 绝对禁止：局部擦除、涂抹、克隆图章掩盖缺陷；同一区域复制粘贴充当不同条件；局部形变改变形貌；删除或移动比例尺、改变其代表长度；拼接时隐藏接缝；不同样品的图标为同一。
- 自查动作：每个投稿面板都必须能按 `image-log.md` 记录的参数从原始文件重新生成；重生成不出来即视为违规编辑。

## 11.4 原始数据留存

- 保留仪器原始格式、不覆盖不转存：SEM/TEM 的厂商原始格式或原始 TIFF、EBSD 的 .ctf/.ang/.osc、OM 原始文件；导出的 jpg/png 只是派生图。
- 派生图另存带版本号（如 `S3_SEM_5kx_v2_adj.png`），并把采集参数（kV、放大倍数、步长、采集时间、仪器型号）与「原始文件名 → 具体操作参数（如线性 brightness +10 / contrast +15）→ 生成文件名」记进 `image-log.md`。
- 目录：`images/raw/`（只读）、`images/derived/`、`images/final/`、`image-log.md`、`figure-map.md`（图号 ↔ 原始文件 ↔ 处理脚本）。
- 两条线差异：毕设只需本机留存、能当场调出原图；SCI 期刊多要求「原始数据可应要求提供」，部分刊物有源数据上传通道（**未核实**）。

## 11.5 图像查重自查

1. 建 contact sheet：把所有面板（含补充材料）拼成缩略图墙，扫视找相同形貌、缺陷分布与背景纹理。
2. 疑似项叠加：两图裁到同一区域、缩放到同一像素尺寸后半透明叠加，重合即判重复或局部复制。
3. 量化筛查：同批图两两算像素级相似度（如 SSIM）；**不写死阈值**，改为对相似度排名前 10 的图对逐个人工复核。
4. 留痕表 `image-check.md`：图号 / 来源原始文件 / 与哪些图相似 / 判定 / 处置。
5. 同一张原始图裁成两个面板支撑不同结论时，须声明二者来自同一视场。
6. **未核实**：查重软件名称与各期刊是否用自动图像查重，本方案不指定。

## 11.6 曲线与散点图的强制要素

- 必须叠原始散点：只画均值折线会掩盖分布与离群点；同组同色，为防重叠抖动时需说明。
- 误差棒自解释：是 SD、SEM 还是 95%CI，n 多少，写进图注，全篇统一。
- 拟合：给模型、方程、R²（必要时给残差图）；只给曲线不给 R² 判不合格。
- 外推：拟合区间外用虚线并标注「外推」。
- 坐标轴不作视觉欺骗：断轴须标断轴符号；对数轴须声明；纵轴不从 0 开始且未说明即不合格。

## 11.7 图像层面常见硬伤（反例 → 安全做法）

1. 无比例尺，或比例尺与倍数矛盾（5000× 却反算为 2000×）→ 导出后按比例尺反算校验。
2. 只调其中一张面板的亮度对比度 → 全组同参数，或声明成像条件不同。
3. 拼接接缝可见（接缝处亮度突变）→ 拼接前统一亮度、声明拼接，必要时标出接缝。
4. 同一张图出现在两处、或局部复制当新证据 → 走 11.5 流程，确认重复即合并图号并说明。
5. 图注缺 n / 缺误差棒定义 / 缺检验方法 → 用统一图注模板，缺项即退回。
6. 伪彩或色标缺失（EBSD 无 IPF 图例、EDS 无元素配色）→ 每张伪彩图必备图例。
7. 分辨率不足 → 导出前查目标期刊 DPI 与尺寸要求（**未核实**，线图与栅格图要求不同）。
8. 图上箭头、字母、方框在图注中无解释 → 图注逐条解释。
9. 不同倍数的图并排却未说明视场不同 → 每张图独立标比例尺与倍数。
10. 沿用他人图或改编图未获授权/未引用 → 取得许可并按期刊格式标注来源（许可流程**未核实**）。
